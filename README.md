# Лабораторная работа №3: Базы данных и отношения между таблицами
Вариант 20: Учёт потребления коммунальных ресурсов.

## Описание приложения
Приложение представляет собой REST API сервис для автоматизации учёта коммунальных ресурсов, управления помещениями, приборами учёта (счётчиками), фиксации показаний и формирования начислений.

## Основные бизнес-сущности:
1. User (Пользователь) — владелец помещений.
2. Premise (Помещение) — объект недвижимости (адрес, площадь, владелец).
3. Meter (Счётчик)** — прибор учёта ресурсов (тип, серийный номер, тариф, статус).
4. MeterReading (Показание) — переданные данные приборов учёта.
5. UtilityCharge (Начисление) — расчет суммы к оплате на основе показаний и тарифа.

## Реализованные бизнес-операции:
Ввод показания счётчика с автоматической проверкой статуса прибора, сохранением показания и генерацией связанного платёжного начисления (`UtilityCharge`).
